# Calculator
My goal is to a calculator with features to suit my current academic needs. These include
1. Integration / Differentiation - input a function and automatically calculate its derivative, 2nd derivative, graphs, etc.
2. Function outputs for a range of specified inputs
3. Function graph generator for specified amount of graphs
4. Basic additions (obviously)
5. Factorial of an input
6. Binary Addition / subtraction
etc.

I aim to update this project regularly as my academic needs adapt.
